# mini-erp

A team project built with Python and FastAPI: an AI-assisted mini ERP covering inventory, orders and customers.
## Projeyi nasıl çalıştırırım

1. Repoyu klonla:
   git clone https://github.com/aycgee/mini-erp.git
   cd mini-erp

2. Sanal ortam oluştur ve aç (Windows PowerShell):
   python -m venv .venv
   .venv\Scripts\Activate.ps1

3. Paketleri yükle:
   pip install -r requirements.txt

4. Uygulamayı başlat:
   uvicorn app.main:app --reload

5. Tarayıcıda http://127.0.0.1:8000 adresini aç. API dokümantasyonu için /docs adresine git.
